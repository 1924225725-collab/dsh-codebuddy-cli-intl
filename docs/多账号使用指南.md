# 国际版独立账号环境指南

本功能为每个国际站账号准备独立的 CodeBuddy CLI 配置目录和 Windows 用户目录环境。DSH 会话中选择的带备注模型会固定绑定到对应环境，后续工具结果和图片续轮仍使用同一个账号。

当前仅允许 Windows 上经核查的官方 npm/Node CodeBuddy CLI `2.174.0`。原生 exe、其他系统和其他 CLI 版本不会启用独立账号调用。普通单账号模式仍可使用。实际双账号登录、令牌刷新和官方扣费归属尚未通过真实账号验证。

## 添加并登录

1. 打开插件设置页的“独立账号环境”，输入一个只用于本机识别的备注并新增环境。
2. 为该环境生成官方登录命令。命令会启动专用 PowerShell 脚本；它不会包含或复制你的登录凭据。
3. 在新的 PowerShell 窗口运行命令，并在官方 CLI 登录菜单中选择 **International Site**。核对当前登录身份，完成登录后退出 CLI。
4. 返回设置页，选择该环境并刷新模型目录。
5. 在 DSH 的模型列表中选择带有该备注的模型。已经在运行的会话会继续固定到原环境；切换设置页当前环境不会改变它。

添加、选择和模型目录检查不会发送模型提示。刷新模型目录不会运行 DSH 业务工具。第一次实际对话会按所选模型及官方规则计入账号用量。

## 账号绑定和失败处理

账号模型标识包含环境绑定。用户选择环境 A 的模型后，即使之后把设置页当前环境切换到 B，A 模型对应的调用及工具/图片续轮仍回到 A。若 A 已从管理列表移除，旧会话会明确报错，不会转用 B 或默认登录。当前选了独立环境时，旧的无绑定模型也会被拒绝，需在 DSH 中重新选择带环境备注的模型。

插件不会在 401、网络错误、额度不足、模型权限失败或超时后轮换账号，也不会回落到默认单账号。请在对应隔离环境重新运行生成的官方登录命令，并在 CLI 中选择 International Site。若 CLI 更新到未核查版本，独立账号请求会停止；请等待兼容检查更新，默认单账号模式不受此版本守卫影响。

## 移出环境

移出列表前，先切换到默认单账号或另一个环境，并等该环境的调用结束。插件只从管理列表移除备注，不注销账号，也不删除官方 CLI 登录文件或可能由用户添加的文件。若要注销，请按官方 CLI 支持的流程在对应隔离环境中操作。

## 本地统计和隐私

设置页按环境显示当前插件进程内的请求次数、输入 Token 和输出 Token。插件重启后这些计数会清零；它们不是官方账单、积分余额或额度。官方用量页面是扣费信息的准据。

插件只检查登录文件是否存在及非空，不读取文件内容。登录信息留在各自隔离环境中。账号备注、目录和凭据不会写入请求正文；诊断日志只使用随机环境 ID，不记录备注、目录或登录文件内容。日志不会自动上传。

账号列表、环境目录或锁文件异常时，插件会停止独立账号操作并显示错误，不会静默改用默认账号。已有锁文件会被视为另一进程正在修改列表；插件不会判断锁是否过期或自动接管。
