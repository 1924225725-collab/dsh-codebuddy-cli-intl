# 工作原理 / Architecture

DSH 提供历史和工具说明 → 本地插件转换为结构化提示 → 官方 CLI --print --output-format json → 官方国际服务 → 本地验证结果 → 文字或工具请求返回 DSH。

工具只由 DSH 执行，结果在下一轮历史中传回。CLI 内置工具、MCP 和会话持久化关闭。模型返回不是直接执行的系统命令，需匹配声明的工具。未知工具、损坏参数、冲突或未闭合 JSON 会失败，不自动补全或额外请求模型。

插件不是通用 HTTP API 服务；本机状态接口用于配置页。账户认证和远端请求由官方 CLI 完成。配置目录、提供方 ID 和安装目录与国内插件不同，CLI 系统凭据的存储方式由官方决定。
