# 安装与使用（国际版 0.1.0）

[English](INSTALL.en.md) · [首页](../README.md)

1. 下载 [0.1.0 安装包](../releases/dsh-codebuddy-cli-intl-0.1.0.tgz)，保存到本机。不要选择 GitHub 源码 ZIP。
2. 在 DSH“插件”页导入 .tgz，启用 dsh-codebuddy-cli-intl，打开 llm-codebuddy-cli-intl 组件配置页。找不到入口时重启 DSH，确认安装成功。
3. 点击“一键配置 CLI”。已有安装时自动检测，否则使用官方安装流程；失败时打开配置页的官方安装指南。
4. 复制登录命令到 PowerShell（macOS/Linux 使用终端），进入 CLI 后输入 /login，选择 **International Site**。浏览器登录后返回 CLI，等待认证完成。
5. 刷新模型与倍率，在 DSH 会话中选择国际版提供方的模型，先用新对话发送简短问题。

默认配置目录 ~/.dsh-codebuddy-cli-intl，可在高级设置中更改。原实验版用户保留自己的旧目录；不要复制开发者目录。插件无需填写 Token、Cookie 或密码；配置文件分开不保证 CLI 系统凭据也分开。

![配置页示例](images/ui-setup.png)

模型可见不等于拥有权限或调用成功。倍率取自官方目录，缺失显示未知。输入 Token 包括历史、工具、缓存及 CLI 开销，不是最新问题的字数。剩余积分到官方账号中心查看。

CLI_NOT_FOUND：重新检测或填写实际路径。版本检查通过仅代表程序启动；认证、网络与模型响应需另外确认。超时可先测试短问题，必要时调至 300000–600000 毫秒；延长不能修复认证或网络。格式错误不会猜测补全或自动重试，0.1.0 没有 0.2.5 的持久日志和详细采集功能。

验证文件操作时，在专用演示目录中让 DSH 先读取一个非私密文件；遵循 DSH 原有权限提示。反馈提供插件/DSH/CLI 版本、模型、错误码与复现步骤，勿公开私人对话和凭据。
