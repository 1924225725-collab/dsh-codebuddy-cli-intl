# 安装与使用（国际版 0.1.3）

[English](INSTALL.en.md) · [首页](../README.md) · [故障处理指南](使用与故障处理指南.md)

1. 下载[国际版 0.1.3 安装包](https://github.com/1924225725-collab/dsh-codebuddy-cli-intl/releases/download/v0.1.3/dsh-codebuddy-cli-intl-0.1.3.tgz)，在 DSH 插件管理中导入 `.tgz`。不要导入 GitHub 源码 ZIP。
2. 启用 `dsh-codebuddy-cli-intl`，打开 `llm-codebuddy-cli-intl` 组件配置页。没有看到配置页时，确认插件已启用并重启 DSH。
3. 点击“一键配置 CLI”。已有安装会先检测；没有可用 CLI 时，使用官方国际版安装器或官方 npm 包。安装过程不会读取或导入桌面版 WorkBuddy 凭据。
4. 复制设置页提供的登录命令，在 PowerShell（macOS/Linux 使用终端）运行 CLI，输入 `/login` 并选择 **International Site**。返回终端，等待 CLI 确认登录完成。
5. 回到 DSH，点击“刷新模型与倍率”，在 DSH 会话中选择国际版提供方的模型。先用新对话发送简短问题，再逐步增加任务范围。

默认 CLI 配置目录为 `~/.dsh-codebuddy-cli-intl`，可在设置中更改。它隔离配置文件，但不保证官方 CLI 的系统凭据存储也隔离；切换账号时使用官方登录流程。

## 常见问题

- **CLI_NOT_FOUND**：重新执行“一键配置”，或填写这台电脑上实际的 CLI 可执行文件路径。
- **版本检查通过但模型调用失败**：检查登录、模型权限、网络和额度。版本检查只确认程序可启动。
- **CLI_AUTH_REQUIRED**：运行 `/login`，选择 **International Site**，完成登录后刷新模型。
- **CLI_TIMEOUT**：先拆小任务并检查服务连接，再按需延长单次超时。延长时间不会修复鉴权或冲突结果。
- **模型结果格式错误**：查看配置页中的“故障处理与使用指南”。重试前核对 DSH 已完成的工具和文件状态；插件不会自动重跑操作。

设置页“诊断日志与问题反馈”提供本机日志查看、普通日志导出和清空。普通日志不含对话正文；需要失败原文时，先阅读隐私提示并手动开启一次采集，分享前预览并删除私人信息。详见[使用与故障处理指南](使用与故障处理指南.md)。

插件支持文本输入，工具由 DSH 管理。模型是否可用、账号额度和服务状态由官方判断；剩余额度请在官方账号页面查看。
